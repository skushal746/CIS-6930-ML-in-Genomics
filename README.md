# CIS-6930-ML-in-Genomics
The following repository contains code for the course work: CIS6930 - Machine Learning in Genomics. 
This project is a classifier which classifies the genetic mutation in the genes in 9 categories.
Usually this classification process is done manually which is cumbersome and time consuming.
The code uses the data from the link: https://www.kaggle.com/competitions/msk-redefining-cancer-treatment/overview
